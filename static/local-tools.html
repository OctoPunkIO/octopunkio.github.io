Local Tools Integration

Optional code intelligence connects OctoPunk to language servers you have installed on your Mac. The app runs in Apple's sandbox and uses NSUserUnixTask to run this user-installed proxy. The proxy does not install language servers.

  1. Read the proxy source, then download the proxy.
  2. In OctoPunk, open Settings → Language Servers → Open Integration Folder. If Finder selects io.octopunk.app, right-click it and choose Show Package Contents.
  3. Move the downloaded file into that folder, keeping the exact name octopunk-tool-proxy.
  4. In Terminal, allow the script to run:
    chmod +x "$HOME/Library/Application Scripts/io.octopunk.app/octopunk-tool-proxy"
  5. Return to OctoPunk and click Verify or Check Again. The status should say Integration installed. Refresh the language server list.

Your tools, your choice

Install any language servers you want separately. This integration is optional; GitHub browsing and review work without it. To uninstall the proxy, remove it from the Application Scripts folder.
